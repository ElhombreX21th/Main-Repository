# Doce Sabor Digital

University extension project created to digitize the order workflow and strengthen the online presence of a local artisanal cooperative.

## Context

The cooperative previously relied on manual communication channels for customer interaction and order handling, which created operational friction, response delays and avoidable errors.

## Problem

The business needed a more structured digital workflow to:

- improve customer access
- reduce manual order handling
- organize institutional and product information
- create a foundation for future administrative features

## Solution

A web platform concept was designed to centralize communication, product visibility and digital workflow support for the cooperative.

## Expected Impact

- fewer operational errors
- faster order handling
- stronger digital presence
- better scalability for future improvements
