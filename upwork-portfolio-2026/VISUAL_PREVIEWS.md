# Visual portfolio previews

These five visual reports are generated from the **synthetic output data** of five independent Python portfolio demonstrations. They are **not screenshots of deployed customer software**. Most source projects are command-line tools; the pages are presentation interfaces created to make their structured outputs easier to evaluate.

1. [Python Invoice & Payment Reconciliation](01_invoice_reconciliation/portfolio_preview.svg)
2. [Resumable API-Style Data Synchronization](02_api_sync/portfolio_preview.svg)
3. [Support Ticket Triage & Escalation](03_support_ticket_triage/portfolio_preview.svg)
4. [MedTech Equipment Log Reliability Analyzer](04_medtech_log_monitor/portfolio_preview.svg)
5. [Medical Service SLA Performance Dashboard](05_service_sla_dashboard/portfolio_preview.svg)

Downloadable PNG renderings of the matching HTML visual reports were provided separately to the account owner for use as Upwork portfolio images. The code behind each demonstration is in its parent directory.

All data are fictional. No clients, patients, regulated medical instruments, or third-party production endpoints are involved.
