## 🏆 Projeto vitrine (principal)

## FPConnect / `fpconnect-rca-copilot`

SaaS para suporte técnico e confiabilidade operacional com app web/mobile, backend moderno e stack de produção.

### O que é
Plataforma para centralizar incidentes, estruturar RCA e transformar histórico operacional em inteligência acionável.

### Problema que resolve
- Dados dispersos em canais informais
- Baixa rastreabilidade de ações corretivas/preventivas

- Docker, testes automatizados
- Deploy cloud (Vercel/Railway/Neon)

### Meu papel

- Modelagem de dados e APIs
- Estruturação do fluxo de RCA
- Entrega com foco em operação real
